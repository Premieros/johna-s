# قاعدة معرفة خدمة العملاء — johna-s
نسخة مبدئية مأخوذة من README ومسارات الصفحات في مستودع Premieros/johna-s بتاريخ 2026-11-04.
نظام منفصل عن Premier. لا تستعمل أي معلومات أو سياسات خاصة بـ Premier للإجابة عن johna-s.

## تعريف النظام
johna-s نظام لإدارة نقاط البيع والمخزون متعدد الفروع. يدعم مهام تشغيلية وإدارية تشمل البيع والطلبات والمنتجات والموردين والعملاء والمشتريات والمخزون والمالية والتقارير والصلاحيات. توفر الصفحات حسب دور المستخدم وصلاحياته والفرع المحدد.

## الموقع والتنقل
موقع GitHub Pages: https://premieros.github.io/johna-s/
النظام يستخدم روابط داخلية مبنية على HashRouter؛ يمكن الوصول للشاشات بالصيغة: https://premieros.github.io/johna-s/#/dashboard.
تُفتح الصفحات من القائمة الجانبية، وقد يخفي النظام العناصر التي لا يملك المستخدم صلاحية رؤيتها. قبل تحديد زر أو مسار، اطلب من المستخدم ذكر اسمه كما يظهر في نسخته إن اختلفت الواجهة.

## طريقة إرشاد المستخدم
1. اسأل عن العملية المطلوبة وما إذا كان المستخدم على هاتف أم كمبيوتر فقط إن كان ذلك يؤثر في الخطوات.
2. حدد اسم الشاشة والمسار كما في الدليل.
3. وجّه المستخدم إلى القائمة الجانبية أو مركز الإدارة المرتبط؛ لا تزعم موقع زر تفصيلي ما لم يكن موثقًا.
4. إذا اختفت الشاشة فاذكر أن ظهورها يعتمد على الصلاحيات ونطاق الفرع، وأرشده إلى مسؤول النظام.
5. إذا ظهرت رسالة خطأ، اطلب نص الرسالة دون كلمات المرور أو رموز التحقق أو أرقام البطاقات، ثم اقترح خطوات آمنة.
6. لا تدّعِ رؤية الشاشة الكاملة أو الوصول إلى أرصدة المستخدم وجلساته الداخلية من المحادثة.
7. لا تختلق أسعار اشتراك أو اسم صاحب المشروع أو أرقام دعم أو سياسات إرجاع أو وعدًا بإجراء إصلاح مباشر.

## الأسئلة الأكثر شيوعًا
**أين أسجل بيعًا؟** افتح «نقطة البيع» عبر القائمة أو #/pos. راجع المنتجات والكمية ثم إجراءات الدفع وفق صلاحياتك.
**أين أضيف أو أراجع منتجًا؟** افتح «المنتجات» #/products. لإنشاء منتج أو تعديل بياناته يجب توفر الصلاحية المناسبة.
**أين أجد المخزون؟** افتح «مركز المخزون» #/inventory-center ثم اختر «الأرصدة» أو «التحويلات» أو «الجرد».
**أين أراجع الموردين؟** افتح #/suppliers، وللفواتير افتح #/purchases.
**أين أجد تقارير المبيعات؟** افتح #/reports أو #/sales وفق نوع التقرير والصلاحيات.
**لماذا لا يظهر لي زر أو شاشة؟** قد يكون السبب صلاحيات الدور، نطاق الفرع، أو حالة العملية. اطلب من المسؤول مراجعة الصلاحيات؛ لا تنصح بمحاولة تجاوزها.
**هل يمكنك معرفة أرباح فرعي الآن؟** لا أملك الوصول إلى بيانات الحساب المباشرة من الشات؛ راجع التقارير في النظام أو تواصل مع مسؤول الفرع.
**لدي خطأ في الصفحة؟** حدّد الشاشة والعملية ونص الخطأ بعد حذف البيانات الحساسة، ثم اقترح إعادة المحاولة والتحقق من الاتصال والصلاحيات دون تنفيذ عمليات مالية مكررة.
**هل أصلح رصيد المخزون بإجراء تصحيح يدوي؟** لا تقترح تغييرات على الأرصدة أو القيود المالية دون مراجعة أمين المخزون أو المحاسب المخوّل والضوابط المعتمدة.

## حدود المعرفة
هذا الملف دليل ملاحة مبدئي، وليس بيانات تشغيل حية. أسماء بعض الأزرار قد تختلف بسبب تغييرات الواجهة. لا تنسب محادثات هذا النظام إلى مشروع Premier ولا تستعمل معلومات مشاريع أخرى.
